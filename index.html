Gridfinity multimeter organizer

I designed a storage solution for a Harbor Freight Cen-Tech multimeter that keeps the meter, probe tips, and cable together in a single, compact footprint. The goal was simple: reduce bench clutter while making the tool easier to grab and return.

WorkshopTool organization

Stepped drill bit Gridfinity holder

I built a holder for a set of common stepped drill bits, organizing them by size and keeping the set accessible in a modular storage system. The design focuses on fit, repeatability, and usability in a real workspace rather than just aesthetic appeal.

VH31 movement holder

This project adapts a VH31 quartz movement to watch cases designed for NH-series mechanical movements. It’s a good example of mechanical problem-solving: combining form, tolerance, and compatibility in a small, purposeful part.
